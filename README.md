# 길드머지레이드

재화로 랜덤 유닛을 뽑아 합치고(Merge) 강화해 자동으로 전투하는 방치형 게임

재화를 소모하여 유닛을 소환해 우측 하단 편성목록에 유닛들을 편성하면 화면 좌측에서
START 버튼으로 자동 전투를 시작합니다. 적을 처치하면 골드를 얻고 보스 처치시 다이아를 얻습니다.
골드를 소모해 유닛들의 능력치를 강화할 수 있고 다이아를 소모해 새로운 유닛을 소환 할 수 있습니다.
같은 등급의 유닛을 화면 우측 그리드칸에서 마우스로 드래그 해 합치면 능력치가 더 높은 상위 등급 유닛으로 강화됩니다.

- 개발 형태: 팀 프로젝트
- 개발 기간: 2026-08.31 ~ 2026-09.28
- 개발 인원: 5명
- 개발 환경: Unity, C#
- 담당 분야: UI, 사운드, 옵션 기능

## 담당 기능

### 전투 UI

- 유닛 생성·소멸 및 체력 변경 이벤트와 체력바 UI 연동
- 월드 좌표를 화면 좌표로 변환하여 유닛을 따라가는 체력바 구현
- TMP Sprite Asset과 DOTween을 활용한 데미지 텍스트 연출
- 치명타 및 방어 결과에 따른 데미지 표시 구분
- 체력바와 데미지 텍스트에 오브젝트 풀 사용

### 사운드 시스템

- ScriptableObject 기반 사운드 라이브러리를 구성하여 사운드 데이터 관리
- 사운드 ID를 이용한 BGM 및 효과음 재생 기능 구현
- AudioSource 재사용을 통한 효과음 재생 구조 구현
- AudioMixer를 활용한 전체·BGM·효과음 음량 조절 기능 구현

### 옵션 기능

- 전체·BGM·효과음 음량 조절 및 음소거 기능 구현
- PlayerPrefs를 이용한 사운드 설정 저장 및 불러오기
- 해상도 및 화면 모드 변경 기능 구현
